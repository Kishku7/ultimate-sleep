# Sleep Mods - Consolidated Feature List

Deduplicated behaviors extracted from the 180 filtered Modrinth 'Sleep' mods
(see sleep_mods_research.md). 52 distinct features. Count = number of mods that
implement that behavior. Derived from Modrinth summary descriptions, so a mod may
have extra features only listed on its full project page.
